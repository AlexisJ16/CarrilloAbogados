## 10. GUÍAS PARA GENERACIÓN DE CONTENIDO SEO

### 10.1 Estructura de Artículo Tipo

Todo artículo SEO debe seguir esta estructura:

1. **H1** (incluye keyword principal, 1 solo por artículo)
2. **Introducción** (150-200 palabras, incluye keyword en primer párrafo)
3. **H2s temáticos** (4-6 secciones principales)
4. **H3s de detalle** (donde aplique)
5. **Datos específicos Colombia/SIC** (costos 2026, tiempos reales 6-12 meses)
6. **Errores comunes** (mínimo 2, con ejemplos reales)
7. **FAQ** (5 preguntas frecuentes, implementar FAQ Schema)
8. **CTA final:** "¿Necesitas ayuda? Agenda una consulta gratuita"

### 10.2 Reglas de Contenido

**INCLUIR OBLIGATORIAMENTE:**
- Datos actualizados de costos SIC 2026
- Tiempos reales del proceso (6-12 meses para registro de marca)
- Mínimo 2-3 internal links a otros artículos
- Mínimo 1-2 external links a fuentes autoritativas (SIC, OMPI)
- Alt text con keyword en imágenes

**NO INCLUIR:**
- Información genérica que aplique a cualquier país
- Promesas de resultados garantizados
- Lenguaje de venta agresivo
- Jerga legal excesiva sin explicación

### 10.3 Checklist de Publicación SEO

| Elemento | Validación |
|----------|------------|
| Title tag | 50-60 caracteres, incluye keyword |
| Meta description | 150-160 chars, incluye keyword + CTA |
| URL slug | Sin tildes, minúsculas, incluye keyword |
| H1 | Solo 1, incluye keyword |
| Longitud | 2,000-2,500 palabras |
| Internal links | Mínimo 2-3 |
| External links | Mínimo 1-2 (SIC, OMPI) |
| FAQ Schema | Implementado si hay sección FAQ |
| CTA | Presente al final del artículo |

## 14. REGLAS OPERATIVAS

### 14.1 Principios Fundamentales

1. **Automatización primero, escala después.** No generar contenido sin tener el pipeline de keywords validado.
2. **Datos sobre intuición.** Toda decisión de keywords debe basarse en DataForSEO/SEMrush, no en suposiciones.
3. **Test → Optimize → Scale.** Framework 3×3×3 (3 mensajes × 3 formatos × 3 audiencias).
4. **Simple > complejo.** Preferir soluciones disponibles sobre implementaciones custom.
5. **El humano siempre aprueba.** Ningún contenido se publica sin revisión de Juan.

### 14.2 Convenciones de Naming

| Tipo | Formato | Ejemplo |
|------|---------|---------|
| Artículo blog | `como-registrar-marca-colombia` | URL slug |
| Keyword ID | `KW-REG-001` | En Keywords_Master |
| Cluster | `registro-marcas`, `pi-startups`, `contratacion-estatal` | Nombres fijos |
| Draft | `MW3_Drafts/YYYY-MM-DD_keyword-slug` | Google Docs |

### 14.3 Priorización de Keywords

Fórmula de prioridad en Keywords_Master: `priority_score = volume/10 - kd + cpc*5`

Filtros para selección de keywords:
- **KD < 30** (baja competencia) → prioridad alta
- **Intención transaccional + commercial** → prioridad alta
- **Volume >= 50** → umbral mínimo
- **Long-tail (3-5 palabras)** → preferidas para quick wins
